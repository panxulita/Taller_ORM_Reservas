# Sistema de Reservas de Salas de Estudio

Taller evaluado de Programación II (ICINF1109).

## Tecnologías
- Python 3.10+
- SQLAlchemy 2.x
- SQLite

## Instalación

Instalar las dependencias:

    pip install -r requirements.txt

## Ejecución

    python main.py

La base de datos se crea automáticamente al ejecutar el programa.

## Funcionalidades

1. Registrar salas.
2. Consultar salas.
3. Registrar reservas.
4. Consultar reservas.
5. Cancelar reservas.
